# Desk scene (Blender source)

The models in `public/models/` are generated by the scripts in `scripts/`. You do not need them to run
the site; they are here so the scene can be changed and rebuilt.

## Setup (once)

```bash
uv venv --python 3.13 .venv-blender
uv pip install --python .venv-blender/bin/python bpy pillow numpy
```

`bpy` is Blender as a Python module (5.x). A full Blender install is not needed. To use a different
interpreter, set `BLENDER_PYTHON`.

## Commands (from the repository root)

```bash
pnpm models                          # build, validate, export public/models/*.glb + src/config/scene.generated.ts
blender/regenerate.sh --compare      # same, plus a render of the opening frame compared with the reference
```

The comparison writes `docs/reference/latest-{render,overlay,edges}.png`. The overlay outlines where the
configured monitor screen lands, in green.

## Layout

- `scripts/config.py`: every position, size and camera value, in metres (Blender axes, Z up)
- `scripts/create_*.py`: one asset each. Each can also run alone (`python -I scripts/create_room.py`) to build and validate it.
- `scripts/build_scene.py`: builds every asset plus the camera and temporary lights; can render a preview
- `scripts/export_all.py`: one GLB per asset, plus the generated TypeScript config
- `scripts/compare.py`: renders the opening frame and compares it with `docs/reference/reference.webp`
- `scripts/shared/`: material library, mesh helpers, export, validation

See `docs/architecture.md` and `docs/asset-inventory.md` for the conventions.

## Legacy scripts

`scene.py`, `bake_export.py` and `make_textures.py` are the original single-file pipeline that produced
`public/models/desk-scene.glb`. They were placed for an older, less accurate camera. They stay here as
source material until every object has been moved into `scripts/` (Phases 2–3), then they are removed.
